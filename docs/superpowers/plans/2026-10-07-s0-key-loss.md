# S0 Key-Loss Spike — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Rust harness that pushes a numbered, mixed-kind key stream through each real input path (local PTY, ssh, ssh+tmux, tmls, tmls over ssh), quiet and under an output flood, and reports missing/duplicate/corrupt events plus p50/p95/p99 delivery latency — so PLAN.md §6 S0's gate can be judged from data.

**Architecture:** One binary `s0` with four subcommands. `s0 recv` runs at the far end of the path in raw mode, tokenises its stdin into numbered events, logs each arrival (wall clock ns) as JSONL and echoes a plain-text ack `A<seq>`. `s0 send` opens a PTY, spawns the path's command inside it (e.g. `ssh -t pcl s0 recv …`), optionally drives a navigation script (for tmls), then writes events at a fixed rate while scanning PTY output for acks; logs sends and ack arrivals as JSONL. `s0 flood` writes styled text at a bounded bytes/s (spawned by `recv --flood`). `s0 report` joins the two logs into counts + percentiles. A shell runner executes the path matrix.

**Tech Stack:** Rust 1.96 (edition 2024), crates `portable-pty` (PTY spawn), `nix` (raw mode termios), `serde`/`serde_json` (JSONL), `clap` (CLI), `regex` (ack scanning). Tests: `cargo test` unit tests + one PTY integration test.

**Spec:** `docs/PLAN.md` §1 (hypothesis), §6 row S0, §9 (benchmark contract). Review context: `docs/reviews/2026-10-07-codex-astra.md` Critical issue 1.

## Review Focus

1. **ESC followed closely by a letter (Alt+x) through tmls/ssh** — a slow or buffered hop may split or merge them; expected: the receiver sees exactly `ESC x` and the report counts it as intact, or flags it `corrupt` with the bytes seen (Task 2 tokenizer test `alt_split_across_reads`).
2. **Ack digits split across two PTY reads or interleaved with redraw escapes** (tmls re-renders rows) — expected: ack scanner keeps a tail buffer and strips CSI/OSC before matching (Task 4 test `ack_across_chunks_with_escapes`).
3. **PTY write returns short / EAGAIN under flood** — expected: sender loops until the full event is written and logs `write_ns` after completion (Task 4 test `short_write_loop`).
4. **Receiver stdout blocked by a slow reader during flood** — expected: acks never block event parsing; flood and acks go through one bounded channel and parsing continues (Task 3 test `recv_keeps_parsing_when_stdout_slow`).
5. **Duplicate vs. reordering** — expected: report distinguishes `dup` (same seq twice), `missing` (never arrived), `corrupt` (seq arrived, payload differs), `reorder` (seq arrived after a higher seq) (Task 5 test `report_classifies`).

```rust
//! The numbered key alphabet. Every event is payload bytes followed by a plain-ASCII marker
//! `#dddddd` that survives any terminal re-rendering. Kind is a pure function of seq.

#[derive(Debug, Clone, Copy, PartialEq, Eq, serde::Serialize, serde::Deserialize)]
pub enum Kind { Letter, Digit, AltLetter, CtrlLetter, ModArrow, FKey, Repeat, Paste }

pub const KINDS: [Kind; 8] = [Kind::Letter, Kind::Digit, Kind::AltLetter, Kind::CtrlLetter,
                              Kind::ModArrow, Kind::FKey, Kind::Repeat, Kind::Paste];

/// Letters safe everywhere (no ctrl-c/d/z/s/q/b collisions once masked to 0x1f).
const LETTERS: &[u8] = b"aefghijklmnoprtuvwxy";
/// Ctrl+letter subset: avoid ^C ^D ^Z ^S ^Q ^B (tmux prefix) ^M ^J ^H ^I ^[ ^G? keep ^G out too (bell).
const CTRL_LETTERS: &[u8] = b"aefklnopruvwxy";

pub fn kind_of(seq: u32) -> Kind { KINDS[(seq % 8) as usize] }

pub fn marker(seq: u32) -> Vec<u8> { format!("#{seq:06}").into_bytes() }

fn letter(seq: u32) -> u8 { LETTERS[(seq / 8 % LETTERS.len() as u32) as usize] }

pub fn expected_payload(seq: u32) -> Vec<u8> {
    let n = seq / 8;
    match kind_of(seq) {
        Kind::Letter => vec![letter(seq)],
        Kind::Digit => vec![b'0' + (n % 10) as u8],
        Kind::AltLetter => vec![0x1b, letter(seq)],
        Kind::CtrlLetter => vec![CTRL_LETTERS[(n % CTRL_LETTERS.len() as u32) as usize] & 0x1f],
        Kind::ModArrow => {
            let m = [b'2', b'3', b'5', b'6'][(n % 4) as usize]; // shift, alt, ctrl, ctrl+shift
            let d = [b'A', b'B', b'C', b'D'][(n / 4 % 4) as usize];
            vec![0x1b, b'[', b'1', b';', m, d]
        }
        Kind::FKey => {
            let code: &[u8] = [&b"15~"[..], b"17~", b"18~", b"19~", b"20~", b"21~"][(n % 6) as usize];
            let mut v = vec![0x1b, b'['];
            v.extend_from_slice(code);
            v
        }
        Kind::Repeat => vec![letter(seq); 5],
        Kind::Paste => {
            let mut v = b"\x1b[200~".to_vec();
            v.extend_from_slice(format!("p{n:04}").as_bytes());
            v.extend_from_slice(b"\x1b[201~");
            v
        }
    }
}

/// The write sequence for seq. Repeat = five single-byte writes (key repeat), then marker.
pub fn encode(seq: u32) -> Vec<Vec<u8>> {
    let payload = expected_payload(seq);
    let mut writes = match kind_of(seq) {
        Kind::Repeat => payload.iter().map(|b| vec![*b]).collect::<Vec<_>>(),
        _ => vec![payload],
    };
    writes.push(marker(seq));
    writes
}
```

```rust
//! Splits the raw byte stream at `#dddddd` markers. Keeps a partial tail (an unfinished marker
//! or escape) between reads.
use crate::event::expected_payload;

#[derive(Debug, Clone, PartialEq, Eq)]
pub struct Arrival { pub seq: u32, pub intact: bool, pub got: Vec<u8> }

#[derive(Default)]
pub struct Tokenizer { buf: Vec<u8> }

impl Tokenizer {
    pub fn new() -> Self { Self::default() }

    pub fn feed(&mut self, bytes: &[u8]) -> Vec<Arrival> {
        self.buf.extend_from_slice(bytes);
        let mut out = Vec::new();
        loop {
            // Find a complete marker: '#' followed by six ASCII digits.
            let Some(h) = self.buf.iter().position(|&b| b == b'#') else { break };
            if self.buf.len() < h + 7 { break; }
            let digits = &self.buf[h + 1..h + 7];
            if !digits.iter().all(u8::is_ascii_digit) {
                // Not a marker: a '#' inside payload (excluded by the alphabet) — skip it.
                self.buf.drain(..=h);
                continue;
            }
            let seq: u32 = std::str::from_utf8(digits).unwrap().parse().unwrap();
            let got = self.buf[..h].to_vec();
            self.buf.drain(..h + 7);
            let intact = got == expected_payload(seq);
            out.push(Arrival { seq, intact, got });
        }
        out
    }
}
```

```rust
//! Bounded-rate output flood: 100-byte coloured lines, paced every 10 ms.
use std::io::Write;
use std::time::{Duration, Instant};

pub fn line(i: u64) -> Vec<u8> {
    let body = format!("F{i:08} {}", "x".repeat(70));
    format!("\x1b[3{}m{body:<88}\x1b[0m\r\n", (i % 7) + 1).into_bytes()
}

/// Writes `bytes_per_sec` to `out` until `stop` is set. Blocks on write; the caller decides
/// which thread/fd this runs on.
pub fn run(mut out: impl Write, bytes_per_sec: u64, stop: &std::sync::atomic::AtomicBool) {
    let tick = Duration::from_millis(10);
    let per_tick = (bytes_per_sec / 100).max(1);
    let mut i = 0u64;
    let mut next = Instant::now();
    while !stop.load(std::sync::atomic::Ordering::Relaxed) {
        let mut sent = 0u64;
        while sent < per_tick {
            let l = line(i); i += 1; sent += l.len() as u64;
            if out.write_all(&l).is_err() { return; }
        }
        let _ = out.flush();
        next += tick;
        if let Some(d) = next.checked_duration_since(Instant::now()) { std::thread::sleep(d); }
    }
}

pub fn main(bytes_per_sec: u64) {
    let stop = std::sync::atomic::AtomicBool::new(false);
    run(std::io::stdout().lock(), bytes_per_sec, &stop);
}
```

```rust
//! Far end of a path. Raw-mode stdin → tokenizer → JSONL log + ack on stdout.
//! Parsing never waits on stdout: acks and flood lines go through one channel drained by a
//! writer thread; if the channel is full the ack is dropped (counted) but the arrival is logged.
use crate::{log::{self, Jsonl, RecvRecord}, tokenizer::Tokenizer};
use nix::sys::termios::{self, LocalFlags, InputFlags, OutputFlags, SetArg};
use std::io::{Read, Write};
use std::os::fd::AsFd;
use std::sync::{atomic::{AtomicBool, Ordering}, mpsc, Arc};

pub struct Opts { pub log: std::path::PathBuf, pub flood: Option<u64>, pub ack: bool, pub quit_after: Option<u64> }

pub fn main(o: Opts) -> anyhow::Result<()> {
    let stdin = std::io::stdin();
    let saved = termios::tcgetattr(stdin.as_fd()).ok();
    if let Some(s) = &saved {
        let mut raw = s.clone();
        raw.local_flags.remove(LocalFlags::ECHO | LocalFlags::ICANON | LocalFlags::ISIG | LocalFlags::IEXTEN);
        raw.input_flags.remove(InputFlags::IXON | InputFlags::ICRNL | InputFlags::INLCR | InputFlags::BRKINT | InputFlags::ISTRIP);
        raw.output_flags.remove(OutputFlags::OPOST);
        termios::tcsetattr(stdin.as_fd(), SetArg::TCSANOW, &raw)?;
    }
    // Ask the outer terminal to enable bracketed paste so a paste comes through as 200~/201~.
    let (tx, rx) = mpsc::sync_channel::<Vec<u8>>(4096);
    let stop = Arc::new(AtomicBool::new(false));
    let writer = std::thread::spawn(move || {
        let mut out = std::io::stdout().lock();
        let _ = out.write_all(b"\x1b[?2004h");
        for chunk in rx { if out.write_all(&chunk).is_err() { break; } let _ = out.flush(); }
    });
    if let Some(bps) = o.flood {
        let tx = tx.clone(); let stop = stop.clone();
        std::thread::spawn(move || {
            struct Chan(mpsc::SyncSender<Vec<u8>>);
            impl Write for Chan {
                fn write(&mut self, b: &[u8]) -> std::io::Result<usize> {
                    self.0.send(b.to_vec()).map(|_| b.len()).map_err(|_| std::io::ErrorKind::BrokenPipe.into())
                }
                fn flush(&mut self) -> std::io::Result<()> { Ok(()) }
            }
            crate::flood::run(Chan(tx), bps, &stop);
        });
    }
    let mut log = Jsonl::create(&o.log)?;
    let mut tok = Tokenizer::new();
    let mut buf = [0u8; 65536];
    let mut idx = 0u64; let mut dropped_acks = 0u64;
    let mut stdin = stdin.lock();
    'outer: loop {
        let n = match stdin.read(&mut buf) { Ok(0) | Err(_) => break, Ok(n) => n };
        let wall = log::now_ns();
        for a in tok.feed(&buf[..n]) {
            log.write(&RecvRecord { seq: a.seq, intact: a.intact, got_hex: log::hex(&a.got), wall_ns: wall, idx })?;
            idx += 1;
            if o.ack && tx.try_send(format!("A{:06}\r\n", a.seq).into_bytes()).is_err() { dropped_acks += 1; }
            if o.quit_after.is_some_and(|q| idx >= q) { break 'outer; }
        }
        if idx % 256 == 0 { log.flush()?; }
    }
    stop.store(true, Ordering::Relaxed);
    log.write(&serde_json::json!({"done": true, "arrivals": idx, "dropped_acks": dropped_acks}))?;
    log.flush()?;
    let _ = tx.send(b"\x1b[?2004l\r\nS0DONE\r\n".to_vec());
    drop(tx);
    let _ = writer.join();
    if let Some(s) = saved { let _ = termios::tcsetattr(std::io::stdin().as_fd(), SetArg::TCSANOW, &s); }
    Ok(())
}
```

`ack.rs`:
```rust
//! Finds `A<6 digits>` acks and `S0DONE` in PTY output after stripping escape sequences.
//! State machine so sequences split across reads are handled.
#[derive(Default)]
pub struct AckScanner { tail: Vec<u8>, esc: Esc, pub saw_done: bool }
#[derive(Default, Clone, Copy, PartialEq)]
enum Esc { #[default] None, Esc, Csi, Osc, OscEsc }

impl AckScanner {
    pub fn new() -> Self { Self::default() }
    pub fn feed(&mut self, bytes: &[u8]) -> Vec<u32> {
        let mut plain = std::mem::take(&mut self.tail);
        for &b in bytes {
            self.esc = match self.esc {
                Esc::None => if b == 0x1b { Esc::Esc } else { plain.push(b); Esc::None },
                Esc::Esc => match b { b'[' => Esc::Csi, b']' => Esc::Osc, _ => Esc::None },
                Esc::Csi => if (0x40..=0x7e).contains(&b) { Esc::None } else { Esc::Csi },
                Esc::Osc => match b { 0x07 => Esc::None, 0x1b => Esc::OscEsc, _ => Esc::Osc },
                Esc::OscEsc => Esc::None, // ESC \ (ST)
            };
        }
        let mut out = Vec::new();
        let mut i = 0;
        while i + 7 <= plain.len() {
            if plain[i] == b'A' && plain[i + 1..i + 7].iter().all(u8::is_ascii_digit) {
                out.push(std::str::from_utf8(&plain[i + 1..i + 7]).unwrap().parse().unwrap());
                i += 7;
            } else { i += 1; }
        }
        if plain.windows(6).any(|w| w == b"S0DONE") { self.saw_done = true; }
        let keep = plain.len().min(7);
        self.tail = plain[plain.len() - keep..].to_vec();
        out
    }
}
```
Note: the tail keeps up to 7 bytes so an ack or `S0DONE` split across reads is found on the next feed; acks fully inside the tail are reported once because the scan advances past matched acks — to avoid re-reporting an ack that sits wholly in the kept tail, only keep the bytes *after* the last match when a match occurred (implement: after the loop, `let start = last_match_end.max(plain.len().saturating_sub(7))`). #[derive(Debug, Clone, PartialEq, Eq)]
```rust
pub enum Step { Wait(u64), Text(String), Key(String), ExpectText(String, u64) }

pub fn parse(spec: &str) -> Vec<Step> {
    spec.split(',').filter(|s| !s.is_empty()).map(|s| {
        let mut it = s.splitn(3, ':');
        match (it.next(), it.next(), it.next()) {
            (Some("wait"), Some(ms), _) => Step::Wait(ms.parse().expect("wait ms")),
            (Some("text"), Some(t), _) => Step::Text(t.to_string()),
            (Some("key"), Some(k), _) => Step::Key(k.to_string()),
            (Some("expect"), Some(t), Some(ms)) => Step::ExpectText(t.to_string(), ms.parse().expect("expect ms")),
            _ => panic!("bad nav step {s:?}"),
        }
    }).collect()
}

pub fn key_bytes(k: &str) -> &'static [u8] {
    match k {
        "enter" => b"\r", "esc" => b"\x1b", "tab" => b"\t",
        "up" => b"\x1b[A", "down" => b"\x1b[B",
        "alt+shift+up" => b"\x1b[1;4A", "alt+shift+down" => b"\x1b[1;4B",
        "alt+shift+left" => b"\x1b[1;4D", "alt+shift+right" => b"\x1b[1;4C",
        "j" => b"j", "k" => b"k", "b" => b"b", "q" => b"q",
        other => panic!("unknown key {other}"),
    }
}
```

```rust
pub struct Opts { pub log: PathBuf, pub events: u32, pub rate: f64, pub cols: u16, pub rows: u16,
                  pub nav: Option<String>, pub dump_screen: bool, pub settle_ms: u64, pub cmd: Vec<String> }

pub fn main(o: Opts) -> anyhow::Result<()> {
    // 1. openpty(rows, cols); CommandBuilder from o.cmd with env TERM=xterm-256color; spawn.
    // 2. Reader thread: loop read(master) → push raw bytes to a Mutex<Vec<u8>> screen log (escape-
    //    stripped copy kept for ExpectText / dump) and feed AckScanner; acks → send (seq, now_ns)
    //    over an mpsc channel. Exit on read error/EOF.

    //    ExpectText → poll the stripped screen text every 50 ms until found or timeout (error).
    //    If dump_screen: eprintln the stripped text (last 4000 chars).

}
```
