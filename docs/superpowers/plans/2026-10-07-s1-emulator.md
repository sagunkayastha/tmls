# S1 Emulator Spike Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure whether libghostty-vt 0.2.2 (pinned ghostty a887df42) can serve as tmls-rs's authoritative emulator *and* snapshot source: feed recorded and adversarial terminal streams, snapshot via `fmt::Formatter` (`Format::Vt`) at arbitrary and at sequence-aligned byte boundaries, restore into a fresh terminal, continue the stream, and compare cell-for-cell with an uninterrupted run; report mismatch classes, snapshot sizes and timings; probe portability of the VT snapshot into a second emulator (pyte).

**Architecture:** New crate `spikes/s1` in the workspace. `corpus` = recorded `script` sessions (vim, btop, less, cargo, git, nested tmux, a short Claude Code session) + generated adversarial streams. `grid` = a plain-Rust `Grid` struct (rows × cells: graphemes, fg, bg, style flags, wide/spacer) extracted from `render::RenderState`, plus `TermState` (cursor x/y/visible/style, active screen, modes bitmap, title, pwd, kitty flags, scrollback_rows). `splitter` = a tiny VT state machine (same shape as `spikes/s0/src/ack.rs` stripper) that marks sequence-complete byte offsets. `experiment` = for each (stream, split, strategy) run A→snapshot→C vs D and diff; `report` = Markdown + JSON. A Python helper feeds the VT snapshot to pyte and compares plain text.

**Tech Stack:** Rust 1.96, `libghostty-vt = "0.2.2"` (needs Zig 0.15.2 on PATH: `/data/scratch/zig/y/zig-x86_64-linux-0.15.2`; `GHOSTTY_SOURCE_DIR=/data/scratch/s1-probe/target/debug/build/libghostty-vt-sys-90a98b82a8a190aa/out/ghostty-src` avoids the network clone; the PC Docker image already has Zig 0.15.2), `serde`/`serde_json`, `clap`, `anyhow`, `rand` (seeded splits). Python 3 + `pyte 0.8.2` from `~/Others/tmls/.venv` for the portability probe (read-only use of that venv).

**Spec:** `docs/PLAN.md` §3 (Emulator core — provisional, gate S1), §5.2 (attach = snapshot at offset S + output from S; portable VT reconstruction with documented limits), §6 row S1 ("libghostty-vt pinned build on Linux + Windows MSVC; recorded Claude sessions; snapshot/restore at adversarial byte boundaries = uninterrupted run; portable VT reconstruction quality. Pass: identical results; differences explained"), §10 risks. Probe facts: `/data/scratch/s1-probe/REPORT.md`.

## Review Focus

1. **Split inside a multi-byte UTF-8 char or an escape sequence** — expected: the naive strategy shows a mismatch (parser state lost), the sequence-aligned strategy ("tail carry": snapshot at the last complete boundary ≤ p and replay bytes from that boundary) is identical. Test: Task 4 `split_inside_csi_naive_differs_aligned_identical`.
2. **Alternate screen active at the split** — expected: restore lands on the alt screen with the primary screen content preserved; if the Formatter cannot encode both screens, the results doc says so (Task 4 test `alt_screen_split_roundtrip`).
3. **Scrollback at the split** — expected: `scrollback_rows` and scrollback text equal after restore, or the limit is documented (Task 4 `scrollback_preserved_or_documented`).
4. **Modes and keyboard protocol** — DECCKM, bracketed paste (2004), mouse tracking (1000/1002/1006), kitty keyboard flags, DECTCEM cursor hidden — expected identical after restore (Task 4 `modes_roundtrip`).
5. **Snapshot taken while a hyperlink / wide char / combining sequence is in progress** — expected identical with the aligned strategy (Task 2 corpus includes these; Task 4 compares).

#[cfg(test)]
mod tests {
    use super::*;
    use libghostty_vt::terminal::{Options, Terminal};
    fn term(cols: u16, rows: u16) -> Terminal<'static, 'static> {

        assert_eq!(g.cells[2].text, "c");

        assert_eq!(g.cells[0].text, "日");
        assert!(g.cells[0].wide);
        assert_eq!(g.cells[2].text, "本");

        let ca = capture(&mut a).unwrap(); let cb = capture(&mut b).unwrap();
        assert!(diff(&ca, &ca).is_identical());
        let d = diff(&ca, &cb);
        assert_eq!(d.cell_mismatches.len(), 1);
        assert_eq!(d.cell_mismatches[0].0, 2);

        let mut t = term(5, 2);
        t.vt_write(b"\x1b[?1049h\x1b[?2004h\x1b[?25l");

        assert!(s.alt_screen);
        assert!(!s.cursor_visible);
        assert!(s.modes.iter().any(|(n, v)| n == "bracketed_paste" && *v));

**Interfaces:**

**Interfaces:**
- `experiment::Strategy { Naive, Aligned }`; `experiment::Case { stream: String, split: usize, strategy: Strategy }`; `experiment::run_case(bytes: &[u8], case: &Case, cols: u16, rows: u16, scrollback: u32) -> CaseResult { identical: bool, cell_mismatches: usize, state_mismatches: Vec<String>, snapshot_bytes: usize, snapshot_us: u128, restore_us: u128, first_mismatch: Option<String> }`:
  - D: fresh terminal, `vt_write(bytes)`.

  - Aligned: `q = last_boundary_at_or_before(p)`; A ← `bytes[..q]`; S ← snapshot(A); C ← restore(S); C ← `bytes[q..]` (tail carry).
  - Compare `capture(C)` vs `capture(D)`; additionally compare **scrollback text**: `Formatter Plain` with… (check if the Formatter can include scrollback: use `with_selection` over the full history or `scroll_viewport` to top then `RenderState` rows — implement one approach and record which; if neither works, record `scrollback_compared: false`).
