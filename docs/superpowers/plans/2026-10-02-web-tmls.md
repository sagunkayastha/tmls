# web tmls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `tmls web` command: an aiohttp server that shows one big xterm.js terminal attached to a
tmux session, rich status rows for all sessions with Yes/No approve, font zoom, an alert inbox, and a
[Sketch] tab, behind sketchpad's password login.

**Architecture:** One aiohttp process on archbox. A shared poll loop reuses tmls's `hosts` and
`approve` modules to build rows and pushes changes over a WebSocket. Each open terminal is one pty
running the same `tmux -u attach` command as the TUI, bridged over a second WebSocket. Static
page, no build step; xterm.js from jsDelivr.

**Tech Stack:** Python 3.12+, aiohttp, existing tmls modules, xterm.js 5.5 + addon-fit, pytest +
pytest-aiohttp, Playwright (already used by sketchpad's e2e).

**Spec:** `docs/superpowers/specs/2026-10-02-web-tmls-design.md`

## Global Constraints

- New code lives in `src/tmls/web/`; tests in `tests/web/`. Match tmls style: short modules, few
  comments, plain functions, no classes where a function will do.
- Only new runtime dependency: `aiohttp`. Dev: `pytest-aiohttp`. No JS build, no npm.
- No Textual import anywhere under `src/tmls/web/`.
- Bind addresses come from `--bind` (repeatable); never default to `0.0.0.0`. Default port **8794**.
- Login uses sketchpad's credentials file `~/.config/sketchpad/auth.json`
  (`{"username","salt","hash","secret"}`, scrypt `n=2**14, r=8, p=1`), cookie TTL 30 days.
- The repo is public: no LAN IPs, tailnet names or hostnames of the user's machines in committed files
  (use `<LAN-IP>`, `<tailnet>` in docs and examples).
- Run tests with `env -u NO_COLOR uv run pytest -q` (the existing suite must stay green).
- Spec deviations agreed during planning:
  1. `?` rows carry `shown` (the prompt lines from `approve.current`) so Yes/No can pass it back
     to `approve.answer`.
  2. Row second line: `waiting` reason for `?`; Claude session title for Claude sessions; last
     non-empty screen line for plain tmux sessions (a Claude pane's last line is its footer).

## Review Focus

1. **Session names with spaces, quotes, `;` or unicode** — attach, capture and approve must pass them
   as single arguments (all go through `shlex`/argv); covered by a test in Task 5 and Task 3.
2. **Many browser tabs / reloads** — closing a tab must kill its pty (no leaked `tmux attach`
   clients piling up on archbox); covered in Task 5.
3. **Host goes offline mid-session** — rows must flip to offline and not crash the poll loop when
   `list_host` raises or returns `(False, [])`; covered in Task 3.
4. **Expired / forged cookie on a WebSocket** — must close with 4401, never open a pty; Task 2/5.
5. **Big output bursts (e.g. `cat` of a large file)** — pty reader must not block the event loop or
   drop the connection; Task 5 reads in chunks with `loop.add_reader` and sends binary frames.

"""tmls in a browser: one big terminal, status rows, approve, sketch."""
import argparse
from pathlib import Path

from aiohttp import web

from tmls import hosts

STATIC = Path(__file__).parent / "static"


async def healthz(request):
    return web.Response(text="ok")


def make_app(auth_file, hosts_list):
    app = web.Application()
    app["auth_file"], app["hosts"] = auth_file, hosts_list
    app.router.add_get("/healthz", healthz)
    return app


def main(argv=None):
    p = argparse.ArgumentParser(prog="tmls-web")
    p.add_argument("--bind", action="append", required=True, help="address to listen on (repeatable)")
    p.add_argument("--port", type=int, default=8794)
    args = p.parse_args(argv)
    from tmls.web import auth
    app = make_app(auth.AUTH_FILE, hosts.hosts(hosts.read_config()))
    web.run_app(app, host=args.bind, port=args.port)

### Task 2: Login (sketchpad credentials, signed cookie, middleware, Origin check)

**Files:**
- Create: `src/tmls/web/auth.py`, `src/tmls/web/static/login.html`
- Modify: `src/tmls/web/server.py`
- Test: `tests/web/test_auth.py`

**Interfaces:**
- Produces in `auth.py`: `AUTH_FILE`, `SESSION_TTL = 30*24*3600`, `COOKIE = "tmls_session"`,
  `load(path) -> dict | None`, `check_login(creds, user, password) -> bool`,
  `make_cookie(secret, user, now=None) -> str`, `verify_cookie(secret, value, now=None) -> str | None`,
  `same_origin(request) -> bool`.
- Produces in `server.py`: middleware `require_login`; routes `GET /login`, `POST /login`,
  `POST /logout`. Public paths: `/login`, `/healthz`. Unauthenticated HTTP → 302 to `/login`;
  unauthenticated WebSocket upgrade → accept then `close(code=4401)`.

Copy the hashing and cookie format from sketchpad's `auth.py` (same file format, so one password):
`_hash(password, salt_hex) = hashlib.scrypt(password.encode(), salt=bytes.fromhex(salt_hex), n=2**14, r=8, p=1).hex()`;
cookie `base64url(f"{expires}|{user}") + "." + hmac_sha256(secret, payload).hexdigest()`.
`verify_cookie` must return None (not raise) on garbage input (bad base64, missing dot, non-int expiry).
Never write to `auth.json`; if it is missing, every login fails with "no credentials: set a
sketchpad password first".

### Task 3: Rows: build, diff, alerts, poll loop, `/api/events`

**Files:**
- Create: `src/tmls/web/rows.py`
- Modify: `src/tmls/web/server.py`
- Test: `tests/web/test_rows.py`, `tests/web/test_events.py`

**Interfaces:**
- Consumes: `hosts.list_host(host) -> (online: bool, sessions: list[hosts.Session])`,
  `hosts.status(s, seen, started) -> "waiting"|"running"|"failed"|"done"|"idle"`, `hosts.QUIET`,
  `approve.current(host, name) -> list[str] | None`.
- Produces in `rows.py`:
  - `key(host, name) -> str` = `f"{host}/{name}"`
  - `class State` with fields `seen: dict[str,int]`, `started: dict[str,int]`, `marks: dict[str,str]`,
    `rows: dict[str, dict]`, `offline: set[str]`.
  - `build(state, found, extras) -> list[dict]` where `found = [(host, online, sessions)]` and
    `extras = {key: {"line": str|None, "shown": list[str]|None}}`. Each row dict:
    `{"key","host","name","mark","line","waiting","shown","online"}`. Mutates `state.started`
    (`setdefault(host, sessions[0].now - hosts.QUIET)`), `state.marks`, `state.rows`, `state.offline`.
    Offline hosts keep their last known rows with `"online": False`.
  - `diff(old: dict[str,dict], new: list[dict]) -> {"set": [rows changed or new], "gone": [keys]}`
  - `alerts(old_marks, new_rows) -> list[dict]`: one `{"key","name","mark"}` for every row whose mark
    changed to `waiting|done|failed` and whose old mark was known (unknown before = not news).
  - `second_line(s, screen) -> str`: `s.waiting` if mark is waiting; else `s.title or s.name` if
    `s.claude`; else last non-empty line of `screen` (stripped), or `""`.
- Produces in `server.py`: background task `poll(app)` started on `app.on_startup`, cancelled on
  `on_cleanup`; every 2 s: `gather(list_host(h))` for `app["hosts"]` (exceptions → treated as
  offline), capture `tmux capture-pane -p -t ={name}:` (via `prompts._run(prompts._run_argv(host, …))`)
  only for plain-tmux sessions whose activity changed, `approve.current` for waiting Claude
  sessions; then `build` → `diff` → broadcast `{"t":"rows", ...diff}` and `{"t":"alerts","items":[...]}`
  to every open `/api/events` socket. A new socket first receives `{"t":"rows","set":all,"gone":[]}`.
  `POST /api/seen {key}` sets `state.seen[key] = now-on-that-host` (the page calls it when a session is
  selected) so "done" clears like in the TUI.

### Task 5: Terminal bridge `/api/term`

**Files:** Create `src/tmls/web/term.py`; Modify `server.py`; Test `tests/web/test_term_bridge.py`

**Interfaces:**
- Consumes: `hosts.attach_argv(host, name) -> list[str]`.
- Produces in `term.py`: `async def bridge(ws, argv, cols=80, rows=24)`: `pty.fork()`; child
  `os.execvp(argv[0], argv)` with `TERM=xterm-256color`; parent sets non-blocking, registers
  `loop.add_reader(fd, …)` reading up to 65536 bytes and `await ws.send_bytes(chunk)`; incoming text
  frames are JSON `{"t":"in","d":str}` → `os.write(fd, d.encode())`, `{"t":"size","cols":int,"rows":int}`
  → `fcntl.ioctl(fd, termios.TIOCSWINSZ, struct.pack("HHHH", rows, cols, 0, 0))` (the kernel sends
  SIGWINCH); malformed frames are ignored. On child exit (read returns b"" / EIO) send
  `{"t":"exit"}` text and close 1000. On socket close: `remove_reader`, `os.kill(pid, SIGHUP)`,
  `os.waitpid` (non-blocking retry, then SIGKILL after 2 s), close fd.
- Produces in `server.py`: `GET /api/term?host=&name=` WebSocket: login (4401) + origin (4403)
  first; host must be in `app["hosts"]` (else close 4404 with no pty); argv from
  `app["attach_argv"](host, name)` (defaults to `hosts.attach_argv`; tests override it).

- [ ] **Step 1: failing tests** (real pty):
  - override `app["attach_argv"] = lambda h, n: ["sh", "-c", "echo attached-$0; exec cat", n]`;
    connect with `name=my "odd" name;x`; first binary frames contain `attached-my "odd" name;x`;
    send `{"t":"in","d":"hello\n"}` → output echoes `hello`.
  - send `{"t":"size","cols":100,"rows":30}` with argv `["sh","-c","sleep 0.2; stty size"]` →
    output contains `30 100`.
  - close the socket → child pid is gone within 2 s (`os.kill(pid, 0)` raises); expose the pid for
    the test via `app["ptys"]` (set of pids, removed on cleanup).
  - unknown host → close code 4404 and `app["ptys"]` stays empty.
  - child exits by itself (`["sh","-c","echo bye"]`) → client gets `{"t":"exit"}`.
  - a burst: argv `["sh","-c","head -c 2000000 /dev/zero | tr '\\0' x"]` → client receives
    2,000,000 bytes total.
- [ ] **Step 2–4:** implement, pass, suite green. Commit `feat(web): terminal bridge`.

Behaviour:
- Select a row → close the old term socket, open `/api/term?host=&name=` (`wss:` on https), `term.reset()`,

- Font zoom: sizes 10–28, default 14; A−/A+ and Ctrl+−/Ctrl+= (preventDefault, so the browser

- Yes/No → `POST /api/approve` with the row's `shown`; on 409 show a toast with the error.
- Bell: count of unread alerts; clicking opens `#alerts` list; clicking an alert selects that row.
- Socket close with code 4401 → `location = "/login"`. Term socket closes unexpectedly → `#overlay`
  "reconnecting…", retry every 2 s up to 5 times, then "session ended" + `#reattach`. `{"t":"exit"}`
  → "session ended" at once. Events socket reconnects forever with 2 s backoff.
