### Task 1: ECH overlay for empty cells (expected: −70 residuals)

**Files:** `spikes/s1/src/carry.rs` (new `erase_overlay`), tests inline.

- The Formatter prints an empty cell either as nothing (bg lost) or as a space (identity lost). After the Formatter output + existing overlays, emit for every maximal run of **empty-text cells** (`Cell.text == ""`) on the viewport that is (a) followed by non-empty content on the same row, or (b) has a non-default background: `CUP(row+1, col+1)` + `SGR 0` + bg SGR if any + `CSI <n> X` + `SGR 0`. Runs of trailing default-bg empty cells need nothing. Wide-cell spacers are skipped (they are not "empty cells").
- Order: after the hyperlink overlay and before the saved-cursor/CUP tail (ECH does not move the cursor, but keep the final CUP last).
- **Tests (write first):** `ech_overlay_restores_erased_bg_after_ed` (Draft A 2J variant → identical), `ech_overlay_restores_empty_identity_after_el` (Draft A 0K variant → identical), `ech_overlay_leaves_trailing_default_blanks_alone` (no ECH emitted for a plain short line), `residual_text_repro` and `residual_style_only_repro` flipped from `#[ignore]` to passing asserts of *identical*.
- Rerun the matrix → `/data/scratch/s1/results/2026-10-08-s1b-r2-run1/` (same flags: `--cols 120 --rows 40 --scrollback 2000 --seed 1`, corpus v2 incl. skip.txt). Report AlignedCarry total and the residual classes. Commit `s1b-r2: ECH overlay for erased/empty cells`.

### Task 3: soft-wrap carry for resize continuation (expected: 91 → ≤ 10 resize mismatches)

**Files:** `spikes/s1/src/carry.rs`, `spikes/s1/src/handoff.rs`, `spikes/s1/src/experiment.rs`, tests inline.

- Read per-row wrap flags from the terminal at snapshot time (`Terminal::grid_ref(Point{row, col 0})` → `is_wrapped()` / `is_wrap_continuation()` for history + viewport rows). Emit the snapshot so that soft-wrapped logical lines are **joined** (Formatter `with_unwrap(true)`) — this is what lets the restored terminal re-wrap on resize — and fix the known regression: with unwrap the last viewport line and a pending-wrap cursor can re-wrap differently (10 `wrap_pending` cases in S1 run6: cell (119,0) 'a' vs 'p'). Fix: emit the viewport with unwrap **except** rows the flags say are not wrapped, and re-arm pending wrap exactly as today; verify the restored row flags equal the source flags (new `grid::row_flags(term) -> Vec<(bool,bool)>` compared in a new `wrap_flags_equal` field of the case record — keep it OUT of the S1 identity definition; report it as an extra column).
- Handoff: rerun `s1 handoff` → resize-epoch variant. Target ≤ 10/400 mismatches; the survivors classified (history row count vs text).
- **Tests:** `unwrap_snapshot_keeps_wrap_flags` (a 300-col logical line on 80 cols → after restore `row_flags` equal), `resize_after_restore_reflows_like_reference` (restore at 80×24, resize to 100×30 both sides → identical), `wrap_pending_no_regression` (the S1 `wrap_pending` stream, all seeded splits, AlignedCarry identical). Commit `s1b-r2: soft-wrap carry (unwrapped emission + row flag check); handoff resize rerun`.
